# SENTINEL - Smart Environmental Nexus for Trade Intelligence & Networked Enforcement Logic

Malaysia's AI compliance engine for detecting illicit trade across international environmental agreements (MEAs):
* **Basel Convention:** Plastic Scrap (`plastic_forensic_pipeline.joblib`) & E-Waste (`ewaste_forensic_pipeline.joblib`)
* **Montreal Protocol:** Ozone Depleting Substances (`ods_forensic_pipeline.joblib`)
* **CITES Framework:** Endangered Fauna & Protected Timber *(Under Construction)*
* **Stockholm & Rotterdam Conventions:** POPs & Chemicals *(Under Construction)*

### Key Features
* Role-Based Access Control (Public, Gov Agency, Admin)
* Real-time `.joblib` forensic inference engine
* Google Looker Studio analytics & summary report downloads
* Interactive Pydeck Malaysian port threat map
* Admin governance hub with model download and threshold calibration
